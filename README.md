## 💎 Core Innovation & Feature Highlights

### 1. 🎛️ Real-Time 3D Interactive Customizer
- **WebGL / Three.js / React Three Fiber Engine**: Interactive 360° orbit, real-time lighting, reflection probes, and material shader controls.
- **Parametric Section Tuning**: Live manipulation of aluminium profile depths (heavy-duty 27mm, 35mm, and Euro-groove multi-track sections).
- **Multi-Product Spectrum**:
  - Architectural Sliding Doors & Acoustic Windows
  - Custom Heavy-Duty Structural Aluminium Beds
  - Modular Loft Almirahs & Bespoke Bookshelves
  - Acoustic Office Partitions & Industrial Facade Glazing

### 2. 🎨 Materiality & Finish Matrix
- **Electrostatic Powder Coating**: Matte Jet Black, Pure Signal White, Anthracite Grey, Charcoal Satin.
- **Anodized Finishes**: Natural Champagne Gold, Deep Architectural Bronze, Clear Satin Silver.
- **Sublimated Woodgrain Wraps**: Natural Teak, Dark Walnut, Rich Mahogany.
- **Acoustic & Security Glass**: Clear Float, Blue Tinted, Low-E Reflective, Frosted Privacy, Double Glazed Units (DGU).

### 3. 📐 Dynamic Quotation Calculator & Cost Engine
- Instant volumetric calculations based on height, width, track count, aluminium section gauge, glass type, and premium hardware options.
- Transparent breakdown of material costs, glass fabrication, specialized fittings, labor, and transport.
- One-click quotation export with WhatsApp integration for instant factory fabrication scheduling.

### 4. 🏭 Virtual 3D Factory & Showroom Walkthrough
- 3D interactive rendering of SIC Belur's precision cutting machines, CNC routing, corner crimping, and assembly lines.

### 5. 📱 Progressive Web App (PWA)
- Offline precaching powered by `vite-plugin-pwa` and Workbox.
- Installable on iOS, Android, macOS, and Windows with native-like UI fluidity.

## 🏗️ Repository Architecture & Cross-Repo CI/CD

This setup follows a decoupled, secure **Source $\to$ Production Deployment** pattern:

```
┌─────────────────────────────────────────────────────────────┐
│  surajindustrial-source (Private / Source Development Repo) │
│  - React 18, Three.js, TypeScript, Tailwind source          │
│  - 3D Canvas shaders, CAD models, business logic            │
│  - GitHub Actions automated deployment workflow             │
└──────────────────────────────┬──────────────────────────────┘
                               │  git push origin main
                               ▼
┌─────────────────────────────────────────────────────────────┐
│             GitHub Actions Runner (Ubuntu Latest)           │
│  1. Checkout Source Code (actions/checkout@v4)              │
│  2. Setup Node.js 22 (actions/setup-node@v4)                │
│  3. npm install && npm run build (tsc -b && vite build)     │
│  4. Generate 404.html for GitHub Pages SPA routing          │
│  5. Push dist/ to external repo via peaceiris/actions-gh-pages│
└──────────────────────────────┬──────────────────────────────┘
                               │  Authenticated with secrets.GH_PAT
                               ▼
┌─────────────────────────────────────────────────────────────┐
│   surajindustrialcompany.github.io (Public Production Repo) │
│  - Branch: `main` (Force-orphaned static build artifacts)   │
│  - All images & assets available at root:                   │
│    https://surajindustrialcompany.github.io/gallery/...     │
│    https://surajindustrialcompany.github.io/logo.svg        │
└─────────────────────────────────────────────────────────────┘
```

## 🔐 GitHub Secrets & Token Setup

To enable automated deployment from `surajindustrial-source` to `surajindustrialcompany.github.io`:

1. **Create Personal Access Token (`GH_PAT`)**:
   - Go to [GitHub Developer Settings > Personal Access Tokens (classic)](https://github.com/settings/tokens).
   - Generate a new token named `GH_PAT`.
   - Select the **`repo`** scope (Full control of private and public repositories).
   - Copy the token value.

2. **Add Secret to `surajindustrial-source`**:
   - In `surajindustrial-source` $\to$ **Settings** $\to$ **Secrets and variables** $\to$ **Actions**.
   - Add a New repository secret:
     - **Name**: `GH_PAT`
     - **Value**: `<your-personal-access-token>`

3. **Verify GitHub Pages on Deployment Repo**:
   - In [`surajindustrialcompany.github.io`](https://github.com/surajindustrialcompany/surajindustrialcompany.github.io) $\to$ **Settings** $\to$ **Pages**:
     - **Source**: `Deploy from a branch`
     - **Branch**: `main` / `/(root)`

## 💻 Local Development & Engineering

### Prerequisites
- Node.js 18+ (Node 22 recommended)
- npm 9+

### Commands

```bash
# Clone the source repository
git clone https://github.com/surajindustrialcompany/surajindustrial-source.git
cd surajindustrial-source

# Install dependencies
npm install

# Start local development server with HMR
npm run dev

# Compile TypeScript & build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
